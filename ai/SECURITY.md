# SECURITY.md

## Reporting Security Issues

We take the security of OPS seriously. If you discover a security vulnerability, please report it responsibly.

### How to Report

1. **Do NOT** open a public GitHub issue
2. Email security@ops-ai.dev with details
3. Allow 72 hours for response before escalating
4. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

### What to Expect

- Acknowledgment within 48 hours
- Regular updates on progress
- Disclosure timeline communication
- Credit in release notes (if desired)

## Security Best Practices

### For Users

- Keep OPS updated to the latest version
- Review tool permissions before enabling
- Use sandboxed environments for untrusted code execution
- Never run OPS as root/administrator

### For Contributors

- Follow secure coding practices
- Review dependencies for known vulnerabilities
- Use environment variables for secrets (never hardcode)
- Run security scans before PR submission
