# Ops-1.0
## A open-source AI Model is currently in beta

# What is Ops 1.0 ?
### ''Ops 1.0'' is an open-source and free AI model created by OpsAI, which can be used with OpsAgent in conjunction with a terminal (PowerShell) to utilize the model (the AI Agent can only be used within the terminal for now, though a web-based computer control Agent may be released in the future).

# Is the Ops 1.0 model powerful ?
### For us, this AI model: Ops 1.0 is not very powerful. Currently, it can handle data on the computer, control your browser, and complete some basic tasks. We are accelerating the training speed to strengthen its capabilities, so please look forward to it.

# How to use the model ?
### Go to the GitHub repository [opsai-agent/agent](https://github.com/opsai-agent/agent) to install the required files for the terminal, then locate the downloaded files and open install.exe to configure them.

### Once the configuration is successful, it will display "Install successful." Close the terminal and reopen a new terminal (note: not just a new terminal tab).In the terminal, type "opsss" to start chatting with Ops1.0 or other Ops models.
